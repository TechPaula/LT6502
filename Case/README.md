# LT6502 case files

Seems to work well, only note is that for the hex treaded part you need to print it at 98% scale for X ad Y only (leave Z, the length, at 100%)
You will also need to hacksaw off the solid base part used to make it stick to the bed.
I found that half of one of these is enough for both of these, so print one and hacksaw it in half :)

The case could be better, but this is my first effort at a 3D printed design.
I've learned a lot :)

Hinges were based on this https://www.printables.com/model/658393-friction-hinge-mechanism/comments#preview.file.aPNjd
